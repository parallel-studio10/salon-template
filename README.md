# Lumière Studio template

Open `index.html` in a browser to preview the template.

Before using it for a salon, replace these details in `index.html`:

- `LUMIÈRE STUDIO` and the location name
- service names, journal cards, phone number and WhatsApp link
- the Unsplash image URLs with the salon's own licensed photography

The progress line and the mobile navigation are handled in `script.js`. The design is responsive without a build step.
